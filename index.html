말로 시키면 내 컴퓨터에 파일을 만들어 주는 프로그램을 써 봅니다. git, 커밋, 브랜치 같은 말은 오늘 안 나옵니다. 폴더 하나로 끝냅니다. 모두 15분이면 됩니다.

준비물은 자기 노트북 한 대입니다. 프로그램을 깔고 개인 계정으로 로그인하기 때문에, 학교 공용 컴퓨터는 권하지 않습니다. 사정상 공용 컴퓨터를 써야 한다면 맨 아래 주의사항을 먼저 읽으세요.

먼저, 쓸 에이전트 하나만 고르세요

셋 다 결과는 비슷합니다. 하나 고르면 아래 모든 명령어가 그걸로 바뀝니다.

OpenAI 것은 이름이 GPT 가 아니라 Codex 입니다. 제일 많이 헷갈리는 부분입니다.

중요

학교 공용 컴퓨터에서 할 때

먼저 전산실 담당자에게 허락을 받으세요. 이 실습은 컴퓨터에 프로그램을 깝니다 (npm install -g). 대부분의 전산실이 무단 설치를 규정으로 막고 있습니다. 허락이 안 되면 아래 “설치가 막힐 때”의 방법을 쓰거나, 개인 노트북으로 하세요.

실습 자체는 똑같습니다. 다만 내 계정 흔적이 컴퓨터에 남습니다. 그대로 두고 나가면 다음에 쓰는 사람이 내 계정으로 요금을 쓰게 됩니다. 아래 네 가지를 지키세요.

  1. API 키를 명령줄에 직접 치지 마세요 PowerShell 은 친 명령을 전부 ConsoleHost_history.txt 에 자동 저장합니다. $env:KEY = "실제키" 라고 치면 키가 그 파일에 평문으로 남습니다. 아래 Read-Host 방식을 쓰면 키는 안 남습니다
  2. 보안 설정은 바꾸지 마세요 Set-ExecutionPolicy 는 공용 PC 에서 쓰지 마세요. 이름 뒤에 .cmd 를 붙이면 설정을 안 바꾸고도 됩니다
  3. 로그인 창은 시크릿 모드로 브라우저에 구글·OpenAI 계정이 그대로 남습니다. 주소를 복사해 시크릿 창에 붙여 넣으세요
  4. 끝나면 반드시 로그아웃 아래 표대로 하고, 마지막에 정리 명령까지 돌리세요
API 키를 안전하게 넣는 법
$env:GEMINI_API_KEY = Read-Host "API 키 붙여넣기"

기록 파일에는 이 명령만 남고 키는 남지 않습니다. 창을 닫으면 키도 사라집니다.

로그아웃 명령이 안 먹거나 확실히 하고 싶을 때 씁니다. 자격증명 폴더를 통째로 지웁니다.

PowerShell · 실습 끝나고
# 1) 로그아웃 (설치되어 있는 것만 실행됨)
claude.cmd auth logout
codex.cmd logout

# 2) 남은 자격증명 폴더 지우기
Remove-Item -Recurse -Force "$env:USERPROFILE\.gemini",
  "$env:USERPROFILE\.codex", "$env:USERPROFILE\.claude",
  "$env:USERPROFILE\.claude.json" -ErrorAction SilentlyContinue

# 3) 영구 저장된 키가 있으면 제거
[Environment]::SetEnvironmentVariable("GEMINI_API_KEY", $null, "User")

# 4) 명령 기록 비우기 (키를 직접 쳤을 경우 대비)
Clear-Content (Get-PSReadLineOption).HistorySavePath -ErrorAction SilentlyContinue

내가 만든 stopwatch 폴더는 여기서 지우지 않습니다. 가져갈 파일을 먼저 챙기고, 탐색기에서 직접 지우세요.

본인 노트북에서는 2번 이후를 돌리지 마세요. 쓰던 로그인이 전부 지워집니다. 공용 컴퓨터에서 자리를 뜰 때만 쓰는 명령입니다.
