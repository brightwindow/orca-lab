말로 시키면 내 컴퓨터에 파일을 만들어 주는 프로그램을 써 봅니다. git, 커밋, 브랜치 같은 말은 오늘 안 나옵니다. 폴더 하나로 끝냅니다. 모두 15분이면 됩니다.

준비물은 자기 노트북 한 대입니다. 프로그램을 깔고 개인 계정으로 로그인하기 때문에, 학교 공용 컴퓨터는 권하지 않습니다. 사정상 공용 컴퓨터를 써야 한다면 맨 아래 주의사항을 먼저 읽으세요.

수업 때 쓴 발표자료 20장 · 설치부터 스킬까지 바로 보기

먼저, 쓸 에이전트 하나만 고르세요

어느 걸 골라도 오늘 결과는 비슷합니다. 하나 고르면 아래 모든 명령어가 그걸로 바뀝니다.

ORCA 는 에이전트를 직접 만들지 않고 터미널에서 도는 CLI 를 대신 띄워 줍니다. 그래서 ORCA 밖에서 먼저 깔고 로그인해 두는 것이 순서입니다. 셋 다 계정이 필요하고 조건이 다른데, Antigravity(agy) 가 제일 간단합니다 — 구글 계정으로 로그인하고 API 키가 필요 없습니다.

OpenAI 것은 이름이 GPT 가 아니라 Codex 입니다. 제일 많이 헷갈리는 부분입니다.

말 걸어서 파일 만들기

3분

아래를 그대로 복사해서 붙여 넣으세요. 한글로 말하면 됩니다.

이걸 붙여 넣기
이 폴더에 stopwatch.html 을 만들어 줘.
- 화면 가운데에 시간이 크게 보이게
- 시작, 정지, 랩, 초기화 버튼 네 개

- 파일은 stopwatch.html 하나만 만들 것 (CSS·JS 도 그 안에)
만들고 나서 이 폴더에서 로컬 서버를 띄우고 주소를 알려 줘.

이렇게 시키는 이유

  • 뭘 만들지 한 줄로 말하기
  • 어떻게 생겼으면 좋겠는지 적기
  • 확인하는 방법까지 시키기
  • 전문 용어 안 써도 됩니다

진행되는 모습

  • 화면이 저절로 움직입니다 — 파일을 쓰는 중입니다
  • 1~3 분 걸립니다
  • 뭘 해도 되냐고 물으면 허용하세요
  • 오른쪽 파일 목록에 stopwatch.html 이 뜨면 성공

중간에 뜨는 창 세 가지 — 전부 허락하면 됩니다

① 폴더를 믿겠냐

Do you trust the files in this folder?
● 1. Trust folder (stopwatch)
  2. Trust parent folder
  3. Don't trust

1번을 고르고 엔터. 내가 방금 만든 폴더라 믿어도 됩니다.

② 계획대로 할까

이 계획대로 진행해도 괜찮을까요?
Awaiting Plan Approval

진행해 줘 라고 답하세요. 기술 스택을 물으면 Single HTML/CSS/JS 를 고릅니다.

③ 실행해도 되냐

Action Required
파일을 써도 될까요?
● Allow / 허용
  Deny / 거부

허용(Allow)을 고르세요. 거부하면 파일이 안 만들어집니다.

④ 파일을 쓸까요 · 명령을 돌릴까요

Would you like to make the
following edits? / run the
following command?
› 1. Yes, proceed (y)

둘 다 1. Yes, proceed. 2번은 다음부터 안 묻는 것이라 실습에서는 쓰지 마세요.

⑤ 글자가 잔뜩 나오고 멈춘 것 같을 때

↑/↓ to scroll
pgup/pgdn to page
q to quit

긴 출력을 읽으라고 잡아 둔 화면입니다. 멈춘 게 아닙니다. q 를 누르면 빠져나옵니다.

묻는 창이 여러 번 떠도 정상입니다. 전부 허용하면 됩니다 — 내가 만든 폴더 안에서만 움직입니다. 되물으면 “알아서 해 줘”도 답이 됩니다. 여기가 오늘의 핵심입니다 — 한글 몇 줄 쳤는데 파일이 생겨 있습니다.

프롬프트를 줄여 쓰지 마세요. “스톱워치 만들어줘” 만 치면 이렇게 됩니다 — 실제로 확인한 결과입니다.

  • stopwatch.html 대신 stopwatch\index.html 처럼 제 맘대로 이름과 위치를 정합니다
  • 구글 폰트 같은 외부 주소를 끌어다 씁니다. 강의실 네트워크가 막으면 글꼴이 깨집니다
  • 시키지 않은 기능(키보드 단축키 등)을 넣습니다

파일은 stopwatch.html 하나만 만들 것 줄을 꼭 남겨 두세요.

지금 폴더가 stopwatch 인지 다시 확인하세요. 엉뚱한 폴더에서 시키면 그 폴더의 파일을 전부 훑고 거기에 파일을 만듭니다. 터미널 경로 끝이 stopwatch 여야 합니다.

# 한 파일 웹페이지

## 규칙

- 파일은 딱 하나만 만든다. CSS 와 JS 도 그 HTML 안에 넣는다.
- 외부 주소를 쓰지 않는다. 구글 폰트, CDN 전부 안 된다.
  인터넷이 끊긴 강의실에서도 그대로 열려야 한다.
- 시키지 않은 기능은 넣지 않는다.
- 파일 이름은 사용자가 말한 그대로 쓴다. 폴더를 새로 만들지 않는다.

중요

학교 공용 컴퓨터에서 할 때

먼저 전산실 담당자에게 허락을 받으세요. 이 실습은 컴퓨터에 프로그램을 깝니다 (npm install -g). 대부분의 전산실이 무단 설치를 규정으로 막고 있습니다. 허락이 안 되면 아래 “설치가 막힐 때”의 방법을 쓰거나, 개인 노트북으로 하세요.

실습 자체는 똑같습니다. 다만 내 계정 흔적이 컴퓨터에 남습니다. 그대로 두고 나가면 다음에 쓰는 사람이 내 계정으로 요금을 쓰게 됩니다. 아래 네 가지를 지키세요.

  1. API 키를 명령줄에 직접 치지 마세요 PowerShell 은 친 명령을 전부 ConsoleHost_history.txt 에 자동 저장합니다. $env:KEY = "실제키" 라고 치면 키가 그 파일에 평문으로 남습니다. 아래 Read-Host 방식을 쓰면 키는 안 남습니다
  2. 보안 설정은 바꾸지 마세요 Set-ExecutionPolicy 는 공용 PC 에서 쓰지 마세요. 이름 뒤에 .cmd 를 붙이면 설정을 안 바꾸고도 됩니다
  3. 로그인 창은 시크릿 모드로 브라우저에 구글·OpenAI 계정이 그대로 남습니다. 주소를 복사해 시크릿 창에 붙여 넣으세요
  4. 끝나면 반드시 로그아웃 아래 표대로 하고, 마지막에 정리 명령까지 돌리세요

지금 쓰는 세 가지(agy·claude·codex)는 모두 브라우저 로그인이라 API 키를 터미널에 칠 일이 없습니다. 그만큼 흘릴 것도 없습니다.

로그아웃 명령이 안 먹거나 확실히 하고 싶을 때 씁니다. 자격증명 폴더를 통째로 지웁니다.

PowerShell · 실습 끝나고
# 1) 로그아웃 (설치되어 있는 것만 실행됨)
claude.cmd auth logout
codex.cmd logout

# 2) 남은 자격증명 폴더 지우기
Remove-Item -Recurse -Force "$env:USERPROFILE\.codex",
  "$env:USERPROFILE\.claude", "$env:USERPROFILE\.claude.json"
  -ErrorAction SilentlyContinue

# 3) 명령 기록 비우기
Clear-Content (Get-PSReadLineOption).HistorySavePath -ErrorAction SilentlyContinue

내가 만든 stopwatch 폴더는 여기서 지우지 않습니다. 가져갈 파일을 먼저 챙기고, 탐색기에서 직접 지우세요.

본인 노트북에서는 2번 이후를 돌리지 마세요. 쓰던 로그인이 전부 지워집니다. 공용 컴퓨터에서 자리를 뜰 때만 쓰는 명령입니다.
