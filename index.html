말로 시키면 내 컴퓨터에 파일을 만들어 주는 프로그램을 써 봅니다. git, 커밋, 브랜치 같은 말은 오늘 안 나옵니다. 폴더 하나로 끝냅니다. 모두 15분이면 됩니다.

먼저, 쓸 에이전트 하나만 고르세요

셋 다 결과는 비슷합니다. 하나 고르면 아래 모든 명령어가 그걸로 바뀝니다.

OpenAI 것은 이름이 GPT 가 아니라 Codex 입니다. 제일 많이 헷갈리는 부분입니다.

실습 1

ORCA 깔기

3분

ORCA 는 내 폴더를 기억해 두고 그 안에서 터미널을 띄워 주는 프로그램입니다. 인공지능을 직접 만들지도, 돈을 받지도 않습니다. 껍데기라고 보면 됩니다.

onorca.dev/download 에서 내 운영체제 것을 받으세요.

Windows

setup.exe 받아서 두 번 누르기

macOS

.dmg 받아서 끌어 넣기. 확인 창이 뜨면 열기

Linux

AppImage 또는 .deb

처음 켜면 홈 폴더를 봐도 되느냐고 묻습니다. 허용하세요. 내 폴더를 찾으려고 묻는 것입니다.

실습 2

에이전트 하나 깔기

3분

ORCA 는 껍데기라서 에이전트는 따로 깔아야 합니다. 안 깔고 이름만 치면 없는 명령이라고 나옵니다.

먼저 Node.js 가 있는지 보기

terminal
node --version

v20 이상이면 됩니다. 아무것도 안 나오면 nodejs.org 에서 LTS 를 받아 까세요.

고른 에이전트 깔기

에이전트를 먼저 고르세요
위에서 에이전트를 고르면 여기에 명령어가 나옵니다.

이러면 성공

  • 2~3 분 걸립니다
  • 깔고 나서 이름 --version 을 쳤을 때 뭔가 뜨면 된 것입니다

막히면

  • npm 이 없다고 하면 Node.js 부터 깔기
  • 권한 오류가 나면 터미널을 관리자로 열기
실습 3

바탕화면에 폴더 하나

1분

탐색기에서 그냥 새 폴더를 만듭니다. 이름은 stopwatch.

  1. 바탕화면에서 오른쪽 클릭 → 새로 만들기 → 폴더
  2. 이름을 stopwatch 로 치기영문 소문자로 하세요
  3. 끝입니다안에 파일이 하나도 없어도 됩니다. 여기다 에이전트가 파일을 만들어 줍니다

Q. git 안 해도 되나

  • 네. 오늘은 안 씁니다

Q. 빈 폴더인데 괜찮나

  • 네. 그게 정상입니다

실습 5

에이전트 띄우기

2분

고르는 목록 같은 건 없습니다. 터미널에 이름을 그냥 칩니다.

terminal · 치고 엔터
위에서 에이전트를 고르면 여기에 나옵니다.
  1. 터미널 칸을 한 번 누르기글자를 칠 수 있게 됩니다
  2. 이름 치고 엔터
  3. 처음이면 로그인하라고 나올 수 있습니다나오는 대로 따라가면 한 번만 하면 됩니다
  4. 프롬프트가 뜨면 준비 끝여기다 한글로 말하면 됩니다. 아직 아무것도 치지 마세요

이러면 성공

  • 터미널 모양이 바뀌었다
  • 뭘 입력하라고 기다리는 중이다

막히면

  • 없는 명령이라고 하면 실습 2 를 안 한 것입니다
  • 돌아가서 깔고 오세요
실습 6

말 걸어서 파일 만들기

3분

아래를 그대로 복사해서 붙여 넣으세요. 한글로 말하면 됩니다.

이걸 붙여 넣기
이 폴더에 stopwatch.html 을 만들어 줘.
- 화면 가운데에 시간이 크게 보이게
- 시작, 정지, 초기화 버튼 세 개
- 1/100 초까지 표시
만들고 나서 이 폴더에서 로컬 서버를 띄우고 주소를 알려 줘.

이렇게 시키는 이유

  • 뭘 만들지 한 줄로 말하기
  • 어떻게 생겼으면 좋겠는지 적기
  • 확인하는 방법까지 시키기
  • 전문 용어 안 써도 됩니다

진행되는 모습

  • 화면이 저절로 움직입니다 — 파일을 쓰는 중입니다
  • 1~3 분 걸립니다
  • 뭘 해도 되냐고 물으면 허용하세요
  • 오른쪽 파일 목록에 stopwatch.html 이 뜨면 성공

에이전트가 되물으면 편하게 답하세요. “알아서 해 줘”도 답이 됩니다. 여기가 오늘의 핵심입니다 — 한글 몇 줄 쳤는데 파일이 생겨 있습니다.

실습 7

브라우저로 열어 보기

2분

에이전트가 알려 준 주소를 브라우저 주소창에 그대로 칩니다.

주소창 · 8000 은 다를 수 있음
http://localhost:8000

localhost 가 뭔가

  • “내 컴퓨터” 라는 뜻입니다
  • 남한테는 안 보입니다
  • 포트 번호는 터미널에 찍힌 숫자로 하세요

눌러서 확인할 것

  • 시작하면 숫자가 올라가는가
  • 정지하면 멈추는가
  • 초기화하면 0 이 되는가

이런 게 뜨면 성공입니다

모양은 사람마다 조금씩 다릅니다. 버튼이 눌리고 숫자가 올라가면 된 것입니다.

기준 스톱워치 눌러 보기

안 열리면 터미널에 서버가 켜져 있는지 보세요. 꺼졌으면 “다시 띄워 줘”라고 하면 됩니다.

참고

증상을 입력하면 걸러집니다.

이럴 때이렇게 해 보기
없는 명령이라고 나옴아직 안 깔린 것입니다. 실습 2 로 돌아가서 깔고 오세요
로그인하라고 함나오는 대로 한 번만 따라가면 다음부터는 안 묻습니다
터미널 경로가 딴 데임왼쪽 목록에서 stopwatch 를 다시 누르세요
주소가 안 열림터미널에 서버가 켜져 있는지 보고, 포트 번호를 다시 확인하세요
에러 글자가 잔뜩 나옴그대로 복사해서 “이 에러 고쳐 줘” 라고 붙여 넣으세요
너무 오래 걸림2~3 분은 정상입니다. 그 이상이면 손 드세요

거의 다 에러 글자를 그대로 붙여 넣고 고쳐 달라고 하면 풀립니다. 그게 이 도구를 쓰는 방법입니다.
